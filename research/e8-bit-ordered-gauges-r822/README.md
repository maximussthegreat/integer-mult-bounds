# Ordered response-kernel gauges on the frozen R822 bit supplier

This additive research package constructs and audits a new bit-supplier witness. It does **not** claim an improved assembled integer-multiplication κ: the current complex supplier remains the binding input. It does not change selected certificates, repository headlines, upstream manuscript files or published state.

## Result and current admission status

The frozen candidate has 175 nonzero helper entrances, total entrance rank 307, and 408 literal entrance XORs. Its eight-replica, nine-stage width-72 packing uses 697 banks per stage and one rank-32 padding child per stage. The numerical bit moment root is approximately **0.0010362123829040513**, versus the frozen bit baseline 0.001021539410806988 (about **1.43636%** supplier improvement). This is a bit-supplier improvement only, not a joint or assembled κ improvement.

The standalone entrypoint passes independent reconstruction, all-column scalar replay, rational frame/source-support checks, owner-route packing, rational moment certification, finite-count checks and negative controls. This is **symbolic finite-contract closure under the retained generic interfaces**, not an unconditional theorem or a supplied combined address/payload machine-code emitter. The precise remaining assumptions are listed below.

The `111` control transfers the compatible subset of PR382's earlier bit gauges onto R822. Its root is enclosed by `[0.001028490312861249899907, 0.001028490312861249899908]`. The ordered candidate prepends ten layers adding 64 pivots, 148 entrance dimensions and 151 XORs. The whole entrance transformation is I+N, with N² nonzero and N³=0; its inverse must be emitted in reverse chronological order.

## Reproduce

Python 3.10 or newer, standard library only, no network:

```
python3 research/e8-bit-ordered-gauges-r822/verify.py
```

Run from any directory. All executed scripts were independently authored for this package. Files under `sources/` are inert reference material or JSON data; no upstream Python, C++, shell program or imported verifier is executed. The entrypoint verifies source hashes, reconstructs R822, derives its response kernel, builds the 111 control and ordered175 witness, checks immutable expected bytes, recomputes prices and runs negative controls. Audit scripts and their finite outputs are integrated through `AUDIT_SCRIPTS.json`.

Only the standalone independently authored checks were run; the inherited repository suites `make verify` and `make gen4-bank-verify` were **not run**. These inherited tests still need the repository maintainer's normal review workflow before adoption.
